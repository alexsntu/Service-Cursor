# Живой поиск iRepair (свой, не стандартный CS-Cart)

| Файл | Где на сервере | Что делает |
|---|---|---|
| `search-index.php` | `/ajax/search-index.php` | Отдаёт JSON-индекс из кэша `var/irepair-search/index.json`. Пересборка: cron www-root **03:30** (`php … rebuild`), если кэша нет или он старше 26 ч — собирается при запросе. |
| `search-synonyms.json` | `/ajax/search-synonyms.json` | Синонимы (айфон/iphone, батарея/аккумулятор…), стоп-слова, популярные услуги (id категорий «Выбор модели»). После правки — `php /var/www/www-root/data/www/dev.irepair.ru/ajax/search-index.php rebuild`. |
| `irepair-search.js` | `/ajax/irepair-search.js` | Окно поиска (лупа в шапке, ⌘K), поиск в браузере по индексу, страница результатов. Подключается в коде шапки (блок 190). |
| `search-page.html` | CS-Cart страница «Поиск», адрес `/search/` | Контейнер страницы результатов (Enter в поиске). |
| стили | общий `irepair-old-header.css` | Компьютер — как Spotlight в macOS, телефон — как поиск в iOS. |

В индексе: модели и серии (категории каталога), страницы «Выбор модели», услуги (цена «от» = минимальная по группе вариаций), страницы и статьи блога. Ссылки относительные.

**После добавления всех услуг** — прогнать поиск по списку услуг и дополнить синонимы.
