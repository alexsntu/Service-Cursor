# Категории — оформление страниц категорий нового сайта iRepair (CS-Cart + UniTheme2)

Порядок работы (с 2026-09-24): **оформляем категорию → заливаем в неё все услуги → проверяем**.
Карточка товара уже готова — см. `../Карточка товара/README.md`.

## Структура папки

`cscart/` повторяет путь на сервере от корня сайта
(`/var/www/www-root/data/www/dev.irepair.ru/`). Всё наше — в модуле **`my_changes`**
(обновления UniTheme2 не затирают).

| Файл (в `design/themes/abt__unitheme2/templates/addons/my_changes/`) | Что делает |
|---|---|
| `blocks/product_list_templates/irepair_service_list.tpl` | Вид списка **«iRepair — Список услуг»** (копия «Компактного списка», `$tmpl='short_list'` — настройки UT2 для компактного списка продолжают действовать) |
| `blocks/product_list_templates/default_params/irepair_service_list.tpl` | Параметры вида (копия `default_params/short_list.tpl`) |
| `blocks/list_templates/irepair_service_list.tpl` | Вёрстка: заголовок «Стоимость услуг по ремонту …» + прайс как на старом сайте (название / «от» цена + время ремонта / «Заказать ремонт» → попап заявки; на телефоне строка целиком ведёт в услугу) |

| `blocks/products/irepair_service_list.tpl` | Шаблон **блока** товаров **«iRepair — Список услуг (блок)»** (копия «Краткого списка» `blocks/products/short_list.tpl`), строки = тот же прайс, что в категории, без заголовка «Стоимость услуг…» (вместо него название блока). Используется в блоке 205 «Популярные услуги» (заполнение «Самые популярные») — шаблон переключает владелец: Дизайн → Макеты → блок → Шаблон. Язык. переменная `irepair_service_list_block`. |

Новые файлы для категорий кладём сюда же, сохраняя серверный путь.

## Как устроено в CS-Cart

- Виды списков CS-Cart ищет в `templates/blocks/product_list_templates/` темы **и** в
  `templates/addons/<включённый модуль>/blocks/product_list_templates/`. Название в админке —
  языковая переменная из `{** template-description:... **}` (`irepair_service_list` = «iRepair — Список услуг»).
- Вид выбирается у категории: Товары → Категории → категория → «Вид списка товаров».
  Через `?layout=` в адресе на неразрешённый вид не переключить.
- Страница категории: `views/categories/view.tpl` темы подключает шаблон выбранного вида.
- В списке категории CS-Cart **не грузит характеристики** товаров — нужные (время ремонта, id 5)
  шаблон достаёт сам: `["product_id"=>$product.product_id]|fn_get_product_features_list:"A"`.
- Тестовая категория: **47 «Ремонт iPhone 17»** — `/catalog/remont-iphone/remont-iphone-17/remont-iphone17/`.

## Страницы категорий: серии и конечные категории (с 2026-09-24)

Генератор `_tools/gen_series.py --config <json>` (конфиги лежат рядом).

- **Серия** (категория с моделями внутри, напр. «Серия iPhone 17»): 2 файла — `<slug>.html` → блок 202
  «Код категории» (баннер + «Выберите модель…»), `<slug>-seo.html` → поле «Описание» категории.
  Все серии iPhone / MacBook Pro, Air / iPad Pro, Classic, Air, Mini — готовы.
- **Конечная категория** (модель, напр. «Ремонт iPhone 17»): конфиг `model-<device>-<model>.json`
  с `"banner_only": true` → один файл `<device>/remont-<model>.html` → блок 202. Заголовок баннера — `<h1>`.
  Под баннером — прайс категории (вид списка «iRepair — Список услуг»).
- Картинки баннеров присылает владелец; обрезаем по контуру (без белых полей), webp →
  `/images/content/catalog/<device>-<model>-model.webp`.
- Код в блоки вставляет владелец сам.

## Прайс «iRepair — Список услуг»: варианты услуги

Если у услуги есть варианты (OEM / AASP …, максимум 4) — под названием «таблетки», выбран самый дешёвый;
нажатие меняет цену строки, пояснение (описание значения характеристики) и данные кнопки «Заказать ремонт».
Телефон: 1–2 варианта — в одну строку с ценой, 3–4 — цена строкой ниже. Нет вариантов — строка как раньше.

## Заливка услуг

Скрипт `../backend/product-import/import_service.py` (описание в самом файле): сначала `--dry-run`,
потом без него. Товары создаются включёнными сразу в нужной категории.
После создания картинки товаров обрезаются по контуру (`crop_images.py`, можно запускать и отдельно
по id товаров); если после обрезки сторона меньше 500 px — скрипт выводит предупреждение, такие фото
владелец потом заменит все разом.

## MacBook: один товар на категорию, два выбора (с 2026-09-28)

Как на старом сайте: «Замена аккумулятора MacBook Pro 13» — **один товар**, в карточке и в прайсе два выбора:
**модель** (характеристика 6 «Модель MacBook», подпись «процессор | A-номера», как в прайсе/калькуляторе,
порядок Intel → M1 → … → M5) и **тип запчасти** (характеристика 7 «Тип запчасти аккумулятора MacBook», OEM/AASP).
Обе — «Вариация как один товар», привязаны к категориям MacBook 90–96 и 23.

- Импорт: `import_service.py --cat 90 --feature 7 --model-feature 6 <все RO id услуги>` — модель из столбца N,
  новые значения модели скрипт добавляет сам; цена — **из таблицы, столбец AY** (для всех устройств; RemOnline —
  только для сверки, у многих новых услуг MacBook там 0); гарантия — из строки «Модуль» (N: «AASP 12 | ОЕМ 3»),
  если столбец L пуст; старый адрес — путь категории из старой базы, если столбец D пуст.
- Прайс: для группы с двумя+ выборами — режим «сетки» (`irepair-sl__row--mx`): ряд «таблеток» на выбор,
  несуществующее сочетание — бледная пунктирная «таблетка», при нажатии берётся ближайшее. Данные —
  `fn_my_changes_irepair_variation_matrix()` в `cscart/app/addons/my_changes/func.php`. У iPhone (один выбор) — как раньше.
- Карточка товара: оба выбора выводит сам CS-Cart (UT2), пояснение к OEM/AASP — как у iPhone.
