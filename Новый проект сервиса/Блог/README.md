# Блог нового сайта (модуль «Блог» CS-Cart + UniTheme2)

Код — в модуле `my_changes`, путь повторяет сервер (`cscart/…` от корня сайта). Шаблоны темы для блога
не правим, а **переопределяем** через `templates/addons/my_changes/overrides/addons/blog/hooks/pages/`:

| Файл | Что делает |
|---|---|
| `page_extra.pre.tpl` | `/blog/` — список статей как на старом сайте (серый фон #f8f8f8, «Блог» + подзаголовок, белые карточки: картинка слева, заголовок, анонс, «Читать полностью ›»; телефон — картинка сверху). В статье — блок «Другие статьи» (3 последние, кроме текущей; появится, когда статей будет больше одной). |
| `page_content.pre.tpl` | Шапка статьи: **главное фото не показываем** (оно только для списка), дата по-русски; текст статьи оформлен стилями сайта (Montserrat/Roboto, таблицы, списки) — через метку `.irepair-blog-post` и `:has()`. |

Тема задаёт шрифт абзацам блога очень «сильным» селектором — поэтому в наших блоках размеры/шрифт с `!important`.

Выкладка: scp → `chown www-root:www-root` → `rm -rf var/cache/templates/* var/cache/registry/*`.

Совет по текстам статей: в тексте не ставить `<h1>` (заголовок страницы уже H1) — разделы начинать с `<h2>`.
