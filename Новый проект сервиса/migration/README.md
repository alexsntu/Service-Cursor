# Подготовка к переезду dev.irepair.ru → irepair.ru

Сверка 2026-10-06: все 3036 адресов из карты старого сайта (`irepair.ru/sitemap2.xml`) проверены на dev.

| Файл | Что внутри |
|---|---|
| `old-sitemap-urls-on-dev-2026-10-06.tsv` | старый адрес → код ответа на dev, число редиректов, конечный адрес |
| `old-urls-404-on-dev-2026-10-06.txt` | 1565 старых адресов, которые на dev отдают 404 |
| `redirect-plan-draft-2026-10-06.tsv` | черновик: старый адрес → ближайший живой раздел нового сайта (на сколько уровней выше) |

Итог сверки: 902 открываются по тому же адресу, 569 — через один 301, **1565 — 404** (цепочек редиректов нет).
404 — в основном услуги iPhone, которых нет на новом сайте (антенны, модем, True Tone, чистка сеток, прошивка и т. п.),
старые посадочные страницы и 60 старых страниц «Выбор модели».

Черновик редиректов — только «на раздел выше». Перед применением: там, где на новом сайте есть та же услуга под другим адресом
(«не включается», «замена задней камеры», «замена динамика»), вести на неё, а не на раздел.
