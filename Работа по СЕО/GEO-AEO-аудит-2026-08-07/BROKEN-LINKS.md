## Побочное наблюдение (не ошибка, но важно для будущей навигации)

В документации проекта используются **два разных префикса** для одних и тех же категорийных страниц:
- `/catalog/remont-*/` — актуальный, отдаёт HTTP 200 напрямую.
- `/servis-apple/remont-*/` — старый префикс, тоже отдаёт HTTP 200, но **через редирект** на `/catalog/remont-*/`.

Оба варианта встречаются в рабочих файлах проекта (например, в `.cursor/rules/`). Технически не ошибка (редирект работает), но для новых материалов (в т.ч. `llms.txt`, canonical-теги) лучше везде использовать `/catalog/remont-*/` как канонический адрес, чтобы не полагаться на редирект.
